# Система администрирования расписания КГУ

Полнофункциональная система управления учебным расписанием для Курганского государственного университета, состоящая из Spring Boot бэкенда и современного React фронтенда.

## 🏗 Архитектура проекта

```
schedule/
├── src/                        # Spring Boot Backend
│   ├── main/java/org/ksu/schedule/
│   │   ├── config/            # Конфигурация безопасности и JWT
│   │   ├── domain/            # Сущности JPA
│   │   ├── repository/        # Spring Data JPA репозитории
│   │   ├── rest/              # REST контроллеры и DTO
│   │   ├── service/           # Бизнес-логика
│   │   └── web/               # Веб-конфигурация
│   └── main/resources/        # Конфигурация и данные
├── frontend/                   # React Frontend
│   ├── src/
│   │   ├── components/        # React компоненты
│   │   ├── services/          # API клиенты
│   │   ├── App.js             # Главное приложение
│   │   └── index.js           # Точка входа
│   ├── public/                # Статические ресурсы
│   └── package.json           # Зависимости npm
├── docker-compose.yml         # Docker конфигурация
├── pom.xml                    # Maven конфигурация
└── README.md                  # Данный файл
```

## 🚀 Возможности системы

### Управление данными
- 📅 **Расписание занятий** - создание, редактирование, удаление записей
- 👨‍🏫 **Преподаватели** - управление информацией о профессорско-преподавательском составе
- 📚 **Предметы** - администрирование учебных дисциплин
- 👥 **Группы** - управление студенческими группами и подгруппами
- 🏛 **Факультеты** - структура университета

### Дополнительный функционал
- 🔐 **Аутентификация** - безопасный доступ с JWT токенами
- 📊 **Импорт Excel** - загрузка данных из файлов
- 🔍 **Фильтрация** - поиск по различным критериям
- 📱 **Адаптивный дизайн** - работа на всех устройствах
- ⚡ **Real-time обновления** - актуальная информация

## 🛠 Технологический стек

### Backend (Spring Boot)
- **Framework**: Spring Boot 3.x
- **Security**: Spring Security + JWT
- **Database**: H2 (разработка), PostgreSQL (продакшн)
- **ORM**: Spring Data JPA
- **Build**: Maven
- **API**: REST с документацией

### Frontend (React)
- **Framework**: React 18
- **UI Library**: Material-UI 5
- **HTTP Client**: Axios
- **Routing**: React Router 6
- **Data Grid**: MUI X Data Grid
- **Styling**: Emotion (встроено в MUI)

## ⚡ Быстрый старт

### 1. Запуск бэкенда

```bash
# Установка и запуск Spring Boot приложения
mvn clean install
mvn spring-boot:run

# Приложение будет доступно на http://localhost:8080
```

### 2. Запуск фронтенда

```bash
# Переход в директорию фронтенда
cd frontend

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start

# Приложение будет доступно на http://localhost:3000
```

### 3. Доступ к системе

Откройте браузер и перейдите по адресу: http://localhost:3000

2. Нажмите "Создать администратора" (данные уже заполнены)

### Переменные окружения

**Backend** (`src/main/resources/application.yml`):
```yaml
server:
  port: 8080
spring:
  datasource:
    url: jdbc:h2:mem:testdb
  security:
    jwt:
      secret: your-secret-key
```

**Frontend** (`frontend/.env`):
```env
REACT_APP_API_URL=http://localhost:8080/api/v1
```

### CORS настройка

Убедитесь, что в Spring Boot настроены CORS для React приложения:

```java
@CrossOrigin(origins = "http://localhost:3000")
```

## 📊 API Endpoints

### Основные группы API:

- **Аутентификация**: `/api/v1/auth/*`
- **Расписание**: `/api/v1/schedule/*` 
- **Преподаватели**: `/api/v1/teacher/*`
- **Предметы**: `/api/v1/subject/*`
- **Группы**: `/api/v1/batches/*`
- **Подгруппы**: `/api/v1/subgroup/*`
- **Факультеты**: `/api/v1/faculty/*`
- **Импорт**: `/api/v1/import/*`

### Примеры запросов:

```bash
# Получить все записи расписания
GET /api/v1/schedule

# Создать новую запись
POST /api/v1/schedule

# Получить расписание группы
GET /api/v1/schedule/subgroup/number/{group_number}
```
